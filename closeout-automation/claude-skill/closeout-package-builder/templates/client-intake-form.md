# Closeout Intake Form (JotForm-style)

Paste this into JotForm (or your intake tool of choice) as a hard
requirement before the closeout working session — same idea as the
transcript's "Annie" intake: get the facts on paper before the call so the
session isn't spent figuring out where to start.

1. Client name
2. Client email
3. Project address
4. Flooring type(s) installed, by room (be specific: species, brand, SKU
   if known)
5. Project start date
6. Project completion date
7. Was a municipal permit required for this scope? If yes, is the final
   inspection closed?
8. Was a subfloor moisture test performed? If yes, attach the report or
   paste the reading and test method.
9. Any known outstanding deficiencies from the final walkthrough?
10. Is the final invoice paid in full? If not, what's outstanding?
11. Do you (the contractor) have a standard workmanship warranty period?
    If not, default to 1 year.
12. Contractor/company name and best contact info for warranty claims.
13. Anything else about this job the AI should know before drafting the
    closeout documents?

Feed the submission straight into Step 1 of `SKILL.md` — it should cover
every required field without needing to ask again.
