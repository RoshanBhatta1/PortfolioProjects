# Sample closeout packages (reference material)

Drop real examples of closeout packages you've sent here so the templates and
the AI document search can be tuned to match what you actually send.

Useful things to drop in:
- The standard warranty letter you send (as .pdf, .docx, or just paste the text
  into a .txt file here)
- A couple of manufacturer warranty PDFs you've attached before
- A couple of manufacturer care/maintenance PDFs you've attached before
- The body text of the email you send with them

**Redact client names, addresses, and phone numbers first** — the wording and
structure is what matters here, not the customer details.

This folder is gitignored by default so nothing sensitive gets pushed by
accident. If you want to share files with Claude, either:
  1. Remove the `samples/` line from .gitignore and commit them deliberately, or
  2. Paste the letter text straight into the chat
